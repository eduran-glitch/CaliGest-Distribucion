# CaliGest

Sistema de gestión y captura de calificaciones.

## Instalación

En una computadora nueva deben instalarse, en este orden:

1. CaliGest Runtime.
2. La actualización más reciente de CaliGest.

El Runtime contiene Python, la interfaz gráfica, las herramientas de Excel y PDF, y el reconocimiento de voz local.

Las actualizaciones posteriores solamente sustituyen el programa. Las materias, alumnos y calificaciones permanecen almacenados localmente en cada computadora.

## Descargas

Los instaladores oficiales se encuentran en la sección **Releases** de este repositorio.

## Privacidad

CaliGest no publica ni sincroniza bases de datos, nombres de alumnos o calificaciones con este repositorio.
